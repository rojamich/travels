{%- comment -%} =========================================================================== trips-in-year.html — which trips and countries belong to a given year =========================================================================== Braces spaced out below so nothing in this comment looks like a real tag: { % include trips-in-year.html year="2026" % } { { year_trips | size } } <- trips that touched that year { { year_countries | size } } <- distinct countries, canonical names THE RULE A trip belongs to a year if its own date range touches that year. Nothing else decides it. A trip spanning New Year appears in both years, which is true and is what the trip page itself says. WHY NOT COUNT FROM POSTS The year page used to work out its trips from post.categories, so a trip with no posts written yet simply did not exist: The Singaporean Stopover is dated January 2026 and was missing from /year/2026/ entirely. Post dates are also publication dates rather than travel dates — 64 posts currently sit outside their own trip's range, some by months — so they are the wrong thing to date a trip by. Countries come from _includes/trip-countries.html — the same rule, and the same _includes/canon-country.html normalisation, that the Countries tile uses — so the two agree. The year layout used to fold names inline WITHOUT consulting the alias table, which meant "USA" and "United States of America" counted as two countries on a year page and one everywhere else. Collection trips (collection_trip: true) are left out. "Party in the USA" spans 2011-2026, so including it would list it on fifteen consecutive year pages and swamp each one's country list. =========================================================================== {%- endcomment -%} {%- assign year_trips = "" | split: "" -%} {%- assign year_countries = "" | split: "" -%} {%- for t in site.trips -%} {%- if t.collection_trip != true and t.start_date and t.end_date -%} {%- assign t_start = t.start_date | date: "%Y" -%} {%- assign t_end = t.end_date | date: "%Y" -%} {%- if t_start <= include.year and t_end >= include.year -%} {%- comment -%} The trip's countries by the same rule the Countries tile uses — _includes/trip-countries.html — so a template trip or a multi-country location string is left out here exactly as it is there. {%- endcomment -%} {%- include trip-countries.html trip=t -%} {%- unless trip_is_template -%} {%- assign year_trips = year_trips | push: t -%} {%- for c in trip_countries -%} {%- unless year_countries contains c -%} {%- assign year_countries = year_countries | push: c -%} {%- endunless -%} {%- endfor -%} {%- endunless -%} {%- endif -%} {%- endif -%} {%- endfor -%} {%- assign year_trips = year_trips | sort: "start_date" -%} {%- assign year_countries = year_countries | sort -%}
