Jekyll prefers _includes/ here over the remote theme's, so this file wins. WHY IT EXISTS The banner prints the post's excerpt under the title, and Jekyll's excerpt is simply the first block of the post. When a post opens with a photo, that first block IS the photo — so the theme rendered a full inside the banner, sitting on top of the banner image. Two photos, overlapping, on the posts that lead with a picture. THE CHANGE One spot, marked below: the lead is stripped of HTML, so an image can never appear there. If stripping leaves nothing — an image-only first block — it falls back to the first text in the post rather than showing an empty line. Text still reads as text; images never make it into the banner. KEEPING IT IN STEP This is a copy, so a theme upgrade will not reach it. If minimal-mistakes changes its banner markup, re-copy the file from https://raw.githubusercontent.com/mmistakes/minimal-mistakes//_includes/page__hero.html and re-apply the marked block.
