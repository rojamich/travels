{%- comment -%} =========================================================================== engagement.html — heart button + view counter for a post =========================================================================== Include at the bottom of a post via {% include engagement.html %}. Reads the post's slug and calls two Netlify Functions (backed by Netlify Blobs) to fetch and update counts. Zero blocking on page render — everything fires async after the DOM is in place. Anti-spam: - Views: incremented once per BROWSER SESSION (sessionStorage flag). Reloading in the same tab does not re-count; opening a new tab does. - Hearts: one per BROWSER (localStorage flag). Once hearted, the icon fills in and the button becomes inert. If the functions fail (network offline, Blobs quota, whatever), the widget shows a dash instead of a count and stays quietly broken — never blocks anything else on the page. =========================================================================== {%- endcomment -%}
