{%- comment -%} =========================================================================== engagement.html — heart + share + view counter for a post =========================================================================== Include at the bottom of a post via {% include engagement.html %}. Widgets: ❤️ Heart — click to toggle on/off. Uses Netlify Functions + Blobs to store the count; localStorage flag tracks per-browser state so clicking again decrements (undo an accidental heart). 📤 Share — native Web Share API on mobile / touch devices; falls back to copy-link on desktop with a tiny toast confirmation. 👁️ Views — passive counter. Incremented once per browser session (sessionStorage flag) so reloads don't inflate. If any function fails (network, quota, whatever) the widget shows a dash and stays quietly broken — never blocks anything else. =========================================================================== {%- endcomment -%}
