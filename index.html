{%- comment -%} ── On this day widget ───────────────────────────────────────────────── Two-pass approach: first find the SMALLEST day-of-year distance to any post from a previous year, then show every post at that distance. Delta 0 = exact today's date match → subtitle: "Posts from ... in previous years." Otherwise → "Closest matches — from ~N days away." Handles the year wrap (e.g. Jan 2 vs Dec 31 is 2 days, not 363) by taking the min of the raw distance and (366 - distance). site.time is the build time, so this refreshes on every deploy. {%- endcomment -%} {%- comment -%} Two-pass: (1) enumerate every past year with posts, (2) for EACH year find its own closest-to-today post. Result: at most one post per year, each the nearest date to today from that year. Sorted newest year first. We track the max delta across the years shown so the subtitle can describe how far off "closest" ended up. {%- endcomment -%} {%- assign today_doy = site.time | date: "%j" | plus: 0 -%} {%- assign this_year = site.time | date: "%Y" -%} {%- assign past_years = "" | split: "" -%} {%- for p in site.posts -%} {%- assign py = p.date | date: "%Y" -%} {%- unless py == this_year -%} {%- unless past_years contains py -%} {%- assign past_years = past_years | push: py -%} {%- endunless -%} {%- endunless -%} {%- endfor -%} {%- assign past_years = past_years | sort | reverse -%} {%- assign on_this_day = "" | split: "" -%} {%- assign max_delta_shown = 0 -%} {%- for year in past_years -%} {%- assign best_post = nil -%} {%- assign best_delta = 999 -%} {%- for p in site.posts -%} {%- assign py = p.date | date: "%Y" -%} {%- if py == year -%} {%- assign p_doy = p.date | date: "%j" | plus: 0 -%} {%- assign d = p_doy | minus: today_doy -%} {%- if d < 0 -%}{%- assign d = 0 | minus: d -%}{%- endif -%} {%- if d > 183 -%}{%- assign d = 366 | minus: d -%}{%- endif -%} {%- if d < best_delta -%} {%- assign best_delta = d -%} {%- assign best_post = p -%} {%- endif -%} {%- endif -%} {%- endfor -%} {%- if best_post -%} {%- assign on_this_day = on_this_day | push: best_post -%} {%- if best_delta > max_delta_shown -%} {%- assign max_delta_shown = best_delta -%} {%- endif -%} {%- endif -%} {%- endfor -%} {%- if on_this_day.size > 0 -%}
